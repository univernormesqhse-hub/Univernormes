## Utilisation
`AnParticles form dur` : couleur `anCol(i)` cyclique sur les quatre stratégies ; pour un autre texte, régénérer `AN_PTS_RAW` (cadre 960 × 520, origine `ox=60`, `oy=cy-260`). `AnScale mast nov expl` : le fléau oscille à partir de `nov`. `AnWeave cross table four dist` et `AnMatrixFinale tiles=[×4] orient choice` : ordre des cases `AN4` (pénétration, développement de produits, développement de marché, diversification ; lignes = marchés, colonnes = produits). `AnGlobe same buyers zones` : cibles en longitude / latitude. `AnRocket radical launch prods markets`.
