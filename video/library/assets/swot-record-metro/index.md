## Utilisation
Pack WebGL : `<GLStage z res>` contient `<Env />`, `<Lights />`, `<Cam p at fov />` puis les objets. `ParticleMorph shapes stage` : `stage` de 0 à 3 fait passer de la forme 0 à la forme 3 (mêmes nombres de points). `CubeMatrix u at N size gap lift dip paint paintK glow cols` : `u` = temps, `at` = début de l'assemblage. `PhotoFX srcs cuts` : `cuts` = [début, durée, mode 0 brûlure / 1 onde / 2 glissé RVB / 3 tourbillon]. `project(point, camKF(t, K))` renvoie la position écran d'un point 3D. Caméra fixe (0, 0, 12) champ 35° : 1 unité = 253,7 px (`wX`, `wY`).
