## Utilisation
`FsBadge n size on` : pastille « nS » dans la couleur du S (n de 0 à 4). `FsShadow place obj freq` : les outils se logent un par un à partir de `place`. `FsReach portee gestes second` : zones de portée vues de dessus. `FsCycle rig ex nouv` : roue qui se fissure à `rig` et se reconstruit à `nouv`.
