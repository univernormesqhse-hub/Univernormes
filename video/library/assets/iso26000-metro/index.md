## Utilisation
`RsSevenRings items=[[libellé, icône, instant, anneau 0-3, angle °], …]` : rayons 0 / 210 / 330 / 430, étiquettes de 240 px (garder ±52° à ±128° sur l'anneau 1). `RsMaze` : la solution `RS_PATH` est fixe, les murs sont générés pour ne jamais la couper. `RsTree tilt` : le travelling vertical descend de 560 px. `RsZoomChain` : facteur ×6 → ×1, traits `non-scaling-stroke`. `RsTelescope a b` : `a` part sur le podium, `b` au-dessus ; l'échange laisse un « ? » (aucune réponse donnée à la place de la voix).
