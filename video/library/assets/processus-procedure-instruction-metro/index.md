## Utilisation
`PpPyramid active subs` : `active` 0 = processus, 1 = procédure, 2 = instruction ; `subs` suit le même ordre (`[libellé, instant]`). `PpLOD steps=[début, zoom 1, zoom 2]`. `PpLoupe spots=[[libellé, icône, instant, x, y], …]` : coordonnées dans le cadre 944 × 784 de la photo. `PpTable rows=[[niveau, icône, rôle, exemple, instant rôle, instant exemple], ×3] boxes` : textes tapés à 34 caractères par seconde. `PpTrapDoors traps=[[libellé, icône, instant, fatal], ×4]`. `PpClaw grab place q` : la carte choisie est la quatrième. Pour un trait animé à bout rond, ne rien dessiner tant que la longueur vaut 0 (sinon un point apparaît).
