## Utilisation
`PdParticles form dur` : couleur par lettre selon x (seuils 285, 495, 700 dans le cadre 960 × 520) ; pour un autre texte, régénérer `PD_PTS_RAW` et les seuils. `PdLetterSlam times=[P, D, C, A]`, `PdCubeTranslate times=[…]` : une ligne par étape de `PD4`. `PdDecisionPipes ok std gap corr` : branche verte puis branche rouge. `PdRollingWheel roll chock` : la roue s'arrête aux deux tiers de la pente.
