# Livraisons — versions légères à télécharger

Versions allégées des capsules (720 × 1280, H.264, voix d'origine, couverture intégrée), pensées pour le téléchargement sur téléphone et l'envoi WhatsApp. Les masters haute qualité (1080 × 1920) restent générés localement dans `video/out/`.

Sur GitHub : ouvrir le fichier, puis le bouton de téléchargement (« Download raw file »).

Les versions « compatible » n'ont qu'une piste vidéo et une piste son (pas d'image de couverture intégrée) : à utiliser si un téléphone ou une application refuse un fichier.
