# Agent illustrations

Base de l'agent de recherche d'illustrations pour les vidéos de motion design QHSE UNIVERSNORMES.
Aucune fonctionnalité n'est encore développée : ce dossier pose uniquement la structure.

## Dossiers

- `images/` : images et illustrations retenues, rangées par vidéo, prêtes à intégrer au montage.
- `recherches/` : traces des recherches (requêtes utilisées, résultats, sources et licences des images).
- `scripts/` : scripts de l'agent (recherche, téléchargement, organisation).

Les dossiers vides contiennent un fichier `.gitkeep` pour que Git les conserve.
